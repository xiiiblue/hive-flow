# 本人交互与简洁中文通知

由智能体理解研发意图，不要求用户记忆桥接业务命令或 UUID。以下是沟通示例，不宣称当前线上已有原生解析，也不授权规范之外的操作。实际账户、来源和工具权限须先核验。

## 手动推进

云端手动控制分支已配置，以下为规范化交互；真实研发尚未执行和验收。

本人说“准备 #42 的执行方案”只触发固定仓库的只读准备，不代表允许改代码。智能体读取 Issue/现有 comments、main SHA、AGENTS 及最少必要源码；不改源码或分支、不运行写检查。#84 暂缓。

一条新通用通知完整承载不可变 `#42 v1`：问题目标、精确文件、基准 SHA、工作/目标分支、逐项允许动作、部署目标、检查/验收/备份/回滚、执行期限和本人结果投递。通知明确请回复 `执行 #42 v1`；bridge 自动添加短编号，本人实际发送例如 `回复 N1 执行 #42 v1`。变更计划另发新版本和新根，旧版本失效；不能改写原方案或让“同意/OK”代替明确批准。

先核验真实 Ditto 根、bridge 作者、固定频道、本人 single 来源、原根唯一版本及未停止/替代，再查已有任务/turn 和回执去重；不能凭标题猜测或盲目重建。通知 3600 秒 TTL 只限制回复受理，不是执行期限。旧 `/review`、record-only 或旧迁移方案均不生成这条新许可。

通过后使用已连接 Mac mini、medium、一个子任务先只读预检，读取 bundled Codex app-server 当前全部适用额度窗口；未知或任一剩余 ≤5% 即停。预检通过才在同一 thread 继续已批准阶段：修改测试→提交推送 PR→指定 SHA 必需 CI 与合并→指定环境备份部署验收。每阶段写前再查额度和停止状态；范围变化、检查失败、撤销或结果不明时暂停核验。一次完整批准覆盖已列动作，不逐步重复询问。详细适配及证据要求见 [手动适配](ADAPTERS.md#dots-云端手动执行适配规范尚未真实执行)。

“查询 #42”只报告现场；“停止 #42”请求合作式停止，必须核验真实终态，不承诺硬杀。结果线程到期可按原本人投递范围新开结果通知，不因此重新获得开发许可。

## 自动模式（当前关闭）

先准备独立会话方案 A1，列明仓库、选择规则、文件范围/动作/环境、东八区起止与截止、扫描频率、预算/数量、额度、停止、验收和回滚。本人在对应新方案根明确“开启 A1”，且实际平台能力已验证后，才可创建会话专用云端定时任务。本轮不创建或开启。

会话内自行扫描范围内已采纳事项、形成计划并推进，不要求逐项手工入队；越界或结果未知即停。历史事项须由新会话明确覆盖，旧 record-only 不默默升级。“停止 A1”或到期只停对应自动扫描及后续阶段，不影响正常问答与 Issue 评审；活动任务仍核验真实终态。细则见 [自动模式](AUTO_MODE.md)。

## 通知模板

```text
#42：已采纳，尚未启动。
下一步：准备范围内的实施计划。
```

```text
#42：测试通过，已合并并部署到获批开发环境。
验证：页面与健康检查通过。
遗留：用户端验收待确认。
```

```text
自动会话已暂停：额度读取不可用。
现场：当前任务保留占用，未继续部署。
下一步：核对额度和任务终态，再按有效授权恢复。
```

模板只示意表达，不是本次真实结果。清楚区分“已请求停止”“实际已停止”，以及“已发送”“接口确认”“用户已看到”。不默认展示 UUID、凭据、原始正文、堆叠日志或一大段协议字段；需要恢复关联时提供最小编号和详情入口。

## 已接通的通用通知与回复

固定可信 bot 在固定私有频道的新根使用 `[wecom:notify]{"text":"正文"}` 主动通知本人。本人看到短编号后发送 `回复 N1 正文`，桥接回到原 Slack 根线程；响应方继续在该线程发 `[wecom:owner]正文`。编号关联一段会话，不精确指向其中某一句；需逐条关联时另发新通知。

当前 TTL 为 3600 秒，从新根接收起计算，后续回复不续期。截止统一显示东八区 `YYYY-MM-DD HH:mm:ss`；已发出的旧消息不追改。到期、编号无效或完整投递未确认时拒绝关联并尽力提示，不猜最近通知。裸“同意/OK”只按原有本人问答处理，不能作为任何旧方案的批准。

一个通知会话的本人回复已真实关联，继续对话回执已有平台 ACK；未据此声称并行逆序、过期或群现场回归通过，详见 [验收记录](MIGRATION.md)。合成测试回复只是测试，不授权业务开发。旧 kind=issue 回传仍失败关闭，旧精确执行命令不得重新解释为新许可；历史语法见 [存档](LEGACY_APPLICATION.md)。
