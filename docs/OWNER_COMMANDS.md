# 本人私聊入口

## 准备执行方案

首版支持本人在企业微信私聊机器人发送：

准备 #84 的执行方案

将数字替换为目标项目的 GitHub Issue 编号。群聊、其他人的私聊及转述命令不开放此能力。仓库由部署方固定配置，消息不能切换仓库或收件人。

当前接入由既有消息桥接和已配置的助手事件处理规则协同完成；本仓库尚未提供可独立部署的命令调度器。仅启动 HiveFlow 进程不等于该入口自动生效。

处理范围：
1. 只读目标 Issue、评论和当前默认分支，记录核对的提交 SHA。
2. 阅读项目约定及最少必要的相关源码、测试，不访问凭据或无关资料。
3. 私聊返回事实、待确认点、拟改范围、尚未执行的验收方法、风险及建议提交方式。

不运行代码或测试，不调用开发执行器，不修改仓库或 Issue；不会把已有 record-only 同意转换成执行许可。直接执行、开启自动开发及部署入口尚未启用。缺少编号、多个编号或语义不明确时，在原私聊澄清。

## 验收状态

普通私聊消息往返已验证。方案准备规则已配置；真实方案请求与返回仍需单独验收，不以配置成功替代端到端验证。
