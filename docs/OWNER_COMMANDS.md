# 本人交互与简洁中文通知

由智能体理解研发意图，不要求用户记忆桥接业务命令或 UUID。以下是沟通示例，不宣称当前线上已有原生解析，也不授权规范之外的操作。实际账户、来源和工具权限须先核验。

## 手动推进：短说明与自然批准

面向本人每条方案说明控制在三至五行，只讲目标、交付到哪、必要风险和一句自然问法。例如：

```text
我会调整登录页标题，让产品名称显示正确。
完成后测试、提交并发布到已核实的指定测试环境。
影响只限标题展示；已核实可回退到当前版本。
可以按这个方案做吗？
```

以上为表达示例，不是实际方案或授权；未经核实不能承诺部署环境、影响范围或回滚可行。一次事先说清并获批准的方案可覆盖修改、测试、提交、推送、PR、合并、明确目标部署和验收，中途不对同范围动作重复询问。不能默认批准任意服务器发布。

完整技术快照仍保存在现有、可审计的执行记录：固定仓库/Issue、目标、精确允许文件、基准、分支、逐项动作、部署目标、检查/验收/备份/回滚、执行期限及本人结果投递。短说明必须在现有审计对应中引用唯一完整计划记录，批准前实际读取并核对二者一致；引用缺失、多候选或摘要未披露实质影响时不能实施。此引用由宿主管理，不要求本人阅读或复述 SHA、文件清单、版本号、UUID。准备方案只读，不改源码/分支、不执行写检查。

对一项有效且唯一关联的明确方案，可信本人说“可以，做吧”即可表达批准意图，不要求固定业务口令。仍须核验实际本人、可信来源、方案关联及有效状态；寒暄、转述、历史同意、其他话题和合成测试均不是许可。普通私聊新根无法可靠关联时，只问最小问题，例如“你说的是登录页标题这项吗？”，不能猜最近任务。平台权限审核未通过时，即使意思明确也不能执行。

只有授权范围实质变化才重新批准。无关 main 文档更新经核实不影响目标文件、依赖、构建/CI、部署脚本、研发规则和验收后，可在执行记录追加新旧基准及判断依据后继续；有影响或未知则先停止核对，不自动扩权。具体规则见 [手动适配](ADAPTERS.md#dots-云端手动执行适配规范尚未真实执行)。

“查询这项进度”只报告现场；“先停下”须可靠关联受影响任务并合作式停止，核验真实终态。结果线程到期可依原本人投递范围另发结果通知，不重获开发许可。

**当前限制：** 平台权限审核已拒绝从企微桥接批准恢复 #84 v3；#84 保持暂停，本轮不是开发授权。自然语言规范改进不表示该路径已经打通，不能绕过审核。现有 bridge 的 `回复 N1 正文` 仍是通用传输关联方式，不是 HiveFlow 业务口令；本轮不修改桥接来消除它。

## 自然表达的验收入口

同意、拒绝、暂缓、停止、查询、条件同意、疑问/转述的统一预期及反例集中维护在 [验收用例](ACCEPTANCE.md#用例与必须观察到的结果)，不在本页另设口令或重复语义表。意图识别、方案关联和权限逐项核验；当前只验证过通用传输，可靠自然批准待核验，#84 的真实恢复仍被平台审核阻止。

## 自动模式（当前关闭）

先准备独立会话方案 A1，列明仓库、选择规则、文件范围/动作/环境、东八区起止与截止、扫描频率、预算/数量、额度、停止、验收和回滚。本人在有效且唯一关联的会话方案中明确表示开启（例如“按这份方案开启自动推进”），且实际平台能力已验证后，才可创建会话专用云端定时任务。本轮不创建或开启。

会话内自行扫描范围内已采纳事项、形成计划并推进，不要求逐项手工入队；越界或结果未知即停。历史事项须由新会话明确覆盖，旧 record-only 不默默升级。可靠关联的“停止自动”或到期只停对应自动扫描及后续阶段，不影响正常问答与 Issue 评审；活动任务仍核验真实终态。细则见 [自动模式](AUTO_MODE.md)。

## 通知模板

```text
#42：已采纳，尚未启动。
下一步：准备范围内的实施计划。
```

```text
#42：测试通过，已合并并部署到获批开发环境。
验证：页面与健康检查通过。
遗留：用户端验收待确认。
```

```text
自动会话已暂停：额度读取不可用。
现场：当前任务保留占用，未继续部署。
下一步：核对额度和任务终态，再按有效授权恢复。
```

模板只示意表达，不是本次真实结果。清楚区分“已请求停止”“实际已停止”，以及“已发送”“接口确认”“用户已看到”。不默认展示 UUID、凭据、原始正文、堆叠日志或一大段协议字段；需要恢复关联时提供最小编号和详情入口。

## 已接通的通用通知与回复

固定可信 bot 在固定私有频道的新根使用 `[wecom:notify]{"text":"正文"}` 主动通知本人。本人看到短编号后发送 `回复 N1 正文`，桥接回到原 Slack 根线程；响应方继续在该线程发 `[wecom:owner]正文`。编号关联一段会话，不精确指向其中某一句；需逐条关联时另发新通知。

当前 TTL 为 3600 秒，从新根接收起计算，后续回复不续期。截止统一显示东八区 `YYYY-MM-DD HH:mm:ss`；已发出的旧消息不追改。到期、编号无效或完整投递未确认时拒绝关联并尽力提示，不猜最近通知。没有可靠上下文的“同意/OK”只按原有本人问答处理，不能猜成某项批准；自然批准是否有效由智能体及平台按可信来源、唯一方案和权限核验，bridge 不作业务判定。

一个通知会话的本人回复已真实关联，继续对话回执已有平台 ACK；未据此声称并行逆序、过期或群现场回归通过，详见 [验收记录](MIGRATION.md)。合成测试回复只是测试，不授权业务开发。旧 kind=issue 回传仍失败关闭，旧精确执行命令不得重新解释为新许可；历史语法见 [存档](LEGACY_APPLICATION.md)。
