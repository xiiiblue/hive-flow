# 工具适配

## 当前适配方式

HiveFlow 只把责任映射到现有工具，不新增业务服务或凭据来源。具体仓库、授权群/本人、账户、环境与时间必须从本次有效方案和宿主受控配置核验，不能从公开示例取得。

|责任|当前采用的工具|使用前核验|
|---|---|---|
|负责人决定与私有结果|dots 原生本人主对话|真实本人、唯一计划对应、有效范围与停止状态|
|需求/代码事实|已授权 GitHub 连接器或仓库工具|完整仓库身份、真实作者、候选 SHA、PR/CI 和写入结果|
|群消息与有限前文|已授权 Slack 连接器及独立 bridge|固定频道、桥接/响应方真实身份、逐条同群与公开用途|
|云端代码依据|dots 自己的云端工作区或授权连接器|远端 SHA、实际读取文件/时间、完整同步或局部替代的区别|
|开发与环境排查|已连接的 Mac mini Codex，medium|目标工作区、原 task/turn、现场、工具权限和明确动作边界|

工具名称随宿主变化，不把某个内部 API 名或模型版本当可移植标准。当前只验证过的能力不能自动移植到其他宿主；其他智能体未适配前不启用。

## 开发任务的阶段衔接

完整授权规则只在 [核心流程](WORKFLOW.md#一次说清完整范围) 定义。批准后在同一个真实任务内按阶段推进，先只读预检基线、脏工作区、相关活动任务和工具，不改文件、不运行写检查；阶段限制在该阶段结束后按原批准范围解除，不能变成永久禁令。

|阶段|写入前核对|必要证据|
|---|---|---|
|修改与测试|授权/期限/停止、文件与风险边界、占用|实际差异与相应检查结果|
|提交、推送、PR|仍在批准范围内，不包含无关修改|真实提交、远端及 PR 对应|
|CI、合并|指定候选的必需检查通过，仍获准合并|真实 CI 和合并结果|
|指定环境交付|明确服务/版本、备份及恢复兼容性，允许部署|部署版本、环境验证、用户可见验收与回滚材料分别记录|

任务关联、阶段和已发生副作用留在现有审计记录，不新增锁评论或状态台账。外部 Codex 的衔接、未知恢复和合作式停止见 [核心流程](WORKFLOW.md#停止未知与已有工作)。

## 环境查询与部署边界

群咨询引出的查询仅限获准环境的相关版本/镜像、健康和必要脱敏日志，明确服务、问题及时间窗；不读凭据和无关个人数据，不运行测试、写配置、重启或部署。缺版本映射则标未知，不能从 main 或服务健康推断部署版本。

真正的开发部署必须另在完整任务范围内明确批准。环境别名不是永久目标；主机地址、SSH 用户、服务路径和恢复材料保留在受控运行说明，公开规范不硬编码。只用已授权连接，不新增认证、扩大权限或启动竞争机器人连接。

## 失败分类

|情况|处理|
|---|---|
|沙箱操作限制|辨明受限层次；仅沿授权及平台支持的正式申请路径处理，不能据此声称网络或免密失效|
|真实权限拒绝|停止对应动作，说明目标、原因和状态；不换命令、工具、账号或子任务绕过|
|连接/认证失败|据实际错误报告，不假称权限通过或盲重连|
|检查失败|停止后续交付，在原目标内修复并完整复验，不降门禁|
|外部结果未知|先核对已有任务和外部事实，不能重放、盲回滚或新建替代任务|
|实际平台耗尽/限流|保存原任务、最后可信进度及结果确定性并报告；不恢复自设额度门禁|

## 能力与验证状态

|能力|已有证据|不能据此声称|
|---|---|---|
|手动分阶段研发|已有修改、测试、合并及另获准部署的实际案例|所有任务、真实账户业务验收或恢复演练均已通过|
|Slack 搜索与线程读取|控制端核验可固定频道/真实作者，关闭周边 context，并读线程|有服务端企微群过滤、可以使用整线程，或群多轮已端到端通过|
|云端同步与局部替代|已有规范要求，须逐次保留实际读取依据|已完整 clone、缓存始终最新或完整群入口已实测|
|环境受限只读排查|明确了请求和脱敏边界|该新入口的现场联调已完成|
|独立桥接传统消息|有通用消息传输及短编号私聊关联的已有验证|群原生引用、真正 @ 人、未 @ 消息接收或自动续接已验证|
|近期消息措辞|短回执代码有独立回归，答复规则已整理|代码推送或规则发布等于线上部署/自动化已同步|
|停止和恢复|同一线程完成一阶段、等待后再续接已演练|运行中硬中断、自动部署恢复或跨工具全局锁已通过|

自动开发关闭；流式演示已撤回，不能将其作为已实现路径。未验证能力保持未验证，测试、平台 ACK、用户可见、授权和交付成功分别判断。当前状态不是持续运行保证，实际配置和线上版本须按任务核对。
