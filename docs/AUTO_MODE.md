# 有期限的自动模式

这是供智能体遵循的目标规范，不是 PVE AutoQueue 或新调度器。**自动开发关闭，未建立真实开发会话。** 现有云端扫描/反馈任务已替换为通用消息协议，保持原触发和频率；它们不等于自动开发已启用。旧的逐项入队试验仅存于 [历史实现](LEGACY_APPLICATION.md)，不作为目标模式的使用要求。

## 独立会话方案 A1 与明确开启

自动模式使用独立会话方案 A1，不能复用某条 Issue 的手动批准或合成测试“同意”。方案一次列明：

- 固定仓库、已采纳事项选择规则，是否明确覆盖历史事项，是否允许新线索/源码巡检。
- 允许文件范围、逐项动作、工作/目标分支、部署环境，事项实际文件不得越过会话边界。
- 东八区明确开始、截止时间与扫描频率；相对期限换算成明确截止，不自动续期。
- 预算、最多事项/任务数量、并发及占用；额度来源、全部适用窗口和严格大于 5% 的门槛。
- 停止条件、检查/验收、预先允许的安全回滚，以及本人通知/结果投递范围。

完整会话快照保存在可审计执行记录中，面向本人仅三至五行概括范围、交付、期限/预算等必要边界和自然问法，不要求阅读技术标识；本人在有效且唯一关联的会话方案上明确表示开启（例如“按这份方案开启自动推进”，桥接仍保留通用短编号关联），云端核验真实来源、唯一方案和当前状态。通知 TTL 是开启回复受理窗口，不代替会话截止。只有授权有效且宿主频率、期限、额度读取、任务查询/停止等能力已核验后，才创建**该会话专用**原生云端定时任务；已有扫描/反馈自动化不自动成为研发执行授权。本轮不创建或开启任何任务。

会话内由智能体自动扫描选择规则内已采纳事项、查重、形成精确实施计划，并在 A1 已准范围内推进，不要求用户逐项手工入队或复述单项固定业务口令。越界、未采纳或状态未知的事项暂停，不自拟更宽的许可。历史 record-only 只是需求决定；只有新会话**明确覆盖历史事项**时才建立新的会话授权关联，不重写原决定。只有会话授权范围实质变化或恢复失效会话才需新的当前授权；无影响的基准漂移按 [手动适配](ADAPTERS.md#基准变化与重新批准) 核验留痕，不默默扩权或反复重审。平台拒绝不能用自然批准绕过。

## 原生任务负责唤起与关闭

使用智能体宿主已验证、已获授权的定时或事件任务。dots 使用自身云端任务，负责定时扫描与截止关闭；事件用于唤起核验，不直接授予执行。事件类型和截止能力以实际平台支持为准，频率必须符合已批准 A1 和平台实际支持，不照搬旧应用的扫描间隔或任意频率。

每次唤醒核验会话仍有效、来源与规则未变、候选实际已采纳、没有重复/占用、额度和工具可用，再串行推进。人工开发也须遵守同一占用记录。查不到权威状态时不创建第二任务。

截至 A1 期限或收到“停止 A1/停止自动”时，只关闭对应研发会话的后续扫描/领取及后续执行阶段，保留正常问答和 Issue 评审；不得停掉通用 bridge 或把其他任务一并关闭。通过现有任务/工作者工具协作暂停活动任务；每个实际副作用前再检查会话与停止状态。不以“定时任务应该会停”替代检查，也不承诺到点强制杀掉正在发生的外部操作。

## 暂停与恢复

额度未知/不足、工作者或外部写结果不明、控制器重启失去现场，会话暂停且保留占用，先核实任务、提交和部署事实。检查失败先暂停后续阶段，在原范围内诊断；不得跳过必需检查去交付，范围或授权变化停止受影响工作并通知。

新鲜额度或迟到的 completed 消息不会重启已停止会话。恢复必须有当前有效的用户依据、明确剩余范围和实际工作者状态；新会话不自动接管旧未知任务。没有原子占用能力时不能宣称跨智能体全局单任务；没有准点关闭能力时不能承诺精确截止。

## 已有消息能力与未验执行链路

真实调度、领取互斥、额度读取、工作者创建与回报必须按宿主分别核验；任务执行沿用 [Mac mini 预检与阶段门槛](ADAPTERS.md#一个-medium-子任务先预检再按阶段继续)，不假设已有全局锁或额度预留。额度优先读取当前环境官方 `get_usage_limits` 并核验实际账号匹配，不假定旧路径存在。Hermes 接入未验，不能复制 dots 的通过结论。目标规范不依赖 `HIVEFLOW_AUTO_EXECUTION_ENABLED`、本地 SQL 或 `[wecom:auto-claim]`；这些属于保留的旧实现试验。

独立 bridge 已支持 `[wecom:notify]{"text":"正文"}` 发起固定本人通知，使用短编号回复原根线程；一个会话来回已实测。`[wecom:owner]` 在该线程延续会话，TTL 当前为 3600 秒且不续期，期限按东八区简洁显示。该消息能力不再是切换阻碍，也不是业务授权或自动模式入口。实际研发调度、占用、额度与工作者链路仍须按当前授权核验；自动开发保持关闭，#84 暂缓。见 [验收记录](MIGRATION.md)。
