# HFL-016：文档维护规则

> 文档状态：Accepted
>
> 责任角色：Director
>
> 本文负责：说明规范、介绍与网站的依赖顺序，以及修改、验证、外部入口同步与公开维护

HiveFlow维护规范与离线辅助，不提供常驻业务应用。全仓权限和事前确认边界由根`AGENTS.md`决定；文档治理和写作分别遵守STD-001、STD-002。本页只说明本目录怎样维护，不另设审批条件。

## 规范、介绍与网站的依赖顺序

HiveFlow内容按以下顺序维护：**HiveFlow规范→HiveFlow介绍→HiveFlow网站**。

|层次|负责位置|内容责任|
|---|---|---|
|规范|本仓库`docs/06-自动化/`|唯一权威执行规则；HFL-003负责协作分工、启动方式、交付终点与Director介入|
|介绍|[HiveFlow手册](../11-手册/05-自动化手册/README.md)|依据规范解释方法、场景、流程和案例，作为网站正文的原始材料|
|网站|独立[flow仓库](https://github.com/xiiiblue/flow)|参考介绍整理经审阅的公开内容，记录所采用的HiveOS版本与章节映射|

职责、授权、交付或停止条件变化时，先在负责该事实的规范中核对并按根规则取得必要确认，再同步介绍，最后更新网站。已经明确授权的规范调整直接落实，不为例行同步重复询问。下游说明不能另设执行规则，也不能因手册或网站已经写出某项承诺，就反过来认定它已经获准。

规范与介绍在同一HiveOS提交中保持一致；网站取材固定包含两者同步修订的完整提交，并核对公开范围与能力证据。原生配置、运行服务和网站发布各自保留实际核验结果，不能把规范提交当成它们已经生效。只更新到其中一层时，报告实际完成层次与剩余项。

## 修改顺序

1. 先核对分支、完整HEAD、工作区与暂存差异，区分本次内容和他人改动。说明实际问题、范围和预期结果，不为演示流程捏造故障或建单。
2. 从[目录](README.md)找到负责该事实的正文。每条规则只在一个主要位置完整维护，其他页概括并链接；指南解释操作，记录保存实际结果，不把接入流水追加到长期规则。
3. 修改行为时核对授权、停止、隐私、目标和验证口径，更新[HFL-012](HFL-012-检查与验收清单.md)中受影响的场景，再按上述依赖顺序同步介绍与网站。表达和结构整理保留已确认含义；重要长期结论的变动按全仓规则处理。
4. 改名、移动或标题变化时，同步Markdown链接和锚点、`spec-manifest.json`、根入口、手册及直接引用路径的离线测试；更新[路径对照](HFL-018-来源迁移与路径对照.md)。保持三条路线与原权限范围，不因重新分组扩大必读或执行权限。
5. 运行下述相关检查，人工审阅实际差异，再在已有授权内提交。示例只用合成事项和占位配置，实际身份、群消息、凭据、配置和运行证据不进本目录。

## 编号与外部入口

正文使用`HFL-三位编号-中文标题.md`，标题首行带同一编号；编号一经使用不回收、不复用。`README.md`和`AGENTS.md`保留工具约定名称；两份JSON保留技术名称。旧英文正文通过Git历史与HFL-018追溯，不复制同一份规则维持旧路径。

任务直接使用HFL-001和HFL-002。两个旧加载兼容页已在外部依赖切换并获确认后移除，依据见[HFL-018](HFL-018-来源迁移与路径对照.md#外部入口切换与旧页移除)。以后调整入口时，先核对外部任务引用和加载缓存，在已有授权内同步并独立读回；确需临时跳转时按STD-001登记用途和移除条件，不复制正文。不得凭仓库改名宣称宿主任务已经同步，也不为文档整理擅自修改任务频率、受众、权限或运行状态。

## 检查怎样选择

在仓库根目录运行；macOS先设置`TMPDIR=/tmp`，本机Python优先使用用户指定的解释器。

```sh
python3 -B scripts/hiveflow/check_docs.py
pnpm docs:check
pnpm diff:check
```

涉及路径、标题、加载清单或外部入口时，再运行：

```sh
python3 -B scripts/hiveflow/test_spec_loading.py
python3 -B scripts/hiveflow/test_migration.py
```

环境查询边界、交付格式、采纳记录和源码过滤分别运行对应的`test_diagnostic_boundaries.py`、`test_delivery.py`、`test_adoption_record.py`、`test_source_snapshot.py`。脚本与测试变化按STD-007运行统一验证；没有改变相关接口时，不为本目录维护读取其他仓库或重跑真实桥接演练。

文档检查只验证本目录及离线工具中的本地链接、锚点和常见敏感形态，不联网，也不能证明所有隐私均已发现。迁移检查另核对编号、目录登记、路径映射和入口衔接。离线测试只证明合成输入下的行为，不证明业务验收或平台强制隔离。
